## 6 账本怎么读（这一节最容易误读）

**这里有一个必须讲清的坑：**

> **当 W 很小（< 100 元）时，π = 收入/W 会虚高**（15 元做出 19.9 元收入 → π = 133%）。
> **这个数是真的，但它不是"资本回报率"，因为分母小到没有意义。**

**所以小 W 阶段的正确读法：**

| 看什么 | 不看什么 |
|---|---|
| **绝对利润**（收入−成本−建设） | π 的百分比 |
| **N（份数）** | 周期数到 10 倍 |
| **复利检查（W 有没有跟着利润长）** | V3（本金没放大就测不了） |

> **一句话：W < 100 元时，这是"现金流账"；W ≥ 1000 元时，才是"资本回报账"。**

**三道门 + 一道检查：**

| 门 | 问什么 | 不过怎么办 |
|---|---|---|
| **V1** | 有没有真实闭环（a > c 且有到账） | 修产品，别放大 |
| **V2** | a 是常数还是运气（变异系数 < 50%） | 攒记录，别放大 |
| **V3** | 放大 10 倍后 a 还在不在（偏差 < 30%） | 回设计，别加钱 |
| **复利** | 利润有没有留在分母里（W 有没有长） | 利润取走 = 你在赚工资，不在造资本 |

## 7 15 元的真实曲线（诚实版）

| 结果 | 概率（我的判断，非精确） | 判据 |
|---|---|---|
| **0 笔成交，30 天** | **最高** | 分发没做起来 → 换渠道，不是换产品 |
| **1–5 笔成交** | 中 | V1 通过，V2 开始积累 |
| **10 笔以上 / 月** | 低 | 有资格谈 V3 |
| **15 元变 150 元（10 倍）** | **很低** | 需要 N ≈ 8 且利润全留存 |
| **变成 1,000 元** | 极低 | 需要 N ≈ 50 且复利不间断 |

**必须写明的一句：**

> **这次实验最可能的结局是"0 笔成交"。**
> **而那不是失败——那是 V1 未通过的数据。**
> **真正会让人亏钱的，不是这一轮 0 成交，是 0 成交之后"加大投入挽回"。**
